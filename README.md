## How I Work

**사용자 입장에서 자연스러운 흐름을 고민합니다.**  
기능이 단순히 동작하는 데 그치지 않고, 사용 과정에서 불편한 지점이 없는지 함께 살펴봅니다.

**근거를 바탕으로 문제를 해결합니다.**  
문제가 발생하면 로그와 지표를 확인하고, 조건을 비교하며 원인을 좁혀 갑니다.

**팀원과 함께 이해할 수 있는 결과를 만듭니다.**  
개발 환경과 검증 방법을 정리하고, 필요한 내용을 문서로 남겨 함께 공유합니다.
